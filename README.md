# Uptane Working Group

This is the Software Supply Chain Security Series working group that works to push standards for [Uptane](https://uptane.org/).

Note that this working group consists of the same personnel as [the steering committee of the Uptane project](https://uptane.org/learn-more/about).

Please refer all broader discussion about the standards, the standardization process, implementations of the project, adopters, and other concerns to the Uptane project.  You can find more information on the project website:
https://uptane.org/

Organizations who would like to support the Working Group are encouraged to join the [Software Supply Chain Security Series](https://join.sscss.io).
